# 📊 Stock Data Analysis Dashboard

An interactive Excel dashboard analyzing historical stock performance for **Amazon, Apple, Google, and Samsung**.

![Dashboard preview](dashboard.png)

## Overview
This project turns raw daily OHLCV data (Open, High, Low, Close, Volume) into an interactive dashboard for comparing company performance over time.

## Features
- Formula-driven pivot tables summarizing price and volume data
- Interactive filters to switch between companies and years
- Styled, themed dashboard layout designed for readability
- Multiple design iterations to refine clarity and usability

## Tools
- Microsoft Excel (pivot tables, formulas, charts, filters)

## Files
- `Stock_Dashboard.xlsx` — the full workbook with data and dashboard
